- 学び(仕様策定時の想定と実測の差):
  1. **依存更新は1回では終わらない**。`next` を上げると ESLint ツールチェーンが入れ替わり、
     それまでツリーになかった脆弱性が現れた。`npm audit` は更新の**後にもう一度**回す必要がある
  2. `postcss` は 8.5.26 になる想定だったが、`next@16.3.3` が 8.5.23 を厳密固定しており、
     それが `@tailwindcss/postcss`(`^8.5.15`)と `vite`(`^8.5.16`)も満たすため
     **1本に dedupe** された。当初想定より良い状態
  3. `brace-expansion` は **1.1.18 と 5.0.9 の2本が残るのが正しい**。`minimatch@3` が `^1.1.7`、
     `minimatch@10` が `^5.0.5` を要求しており semver 上1本化できない。
     「重複は悪」と `overrides` で固めると、どちらかの `minimatch` が壊れる
  4. `next dev` が **`AGENTS.md` を再生成する**(16.3系の挙動。生成元は
     `node_modules/next/dist/server/lib/generate-agent-files.js`)。ファイル全体が
     `<!-- BEGIN:nextjs-agent-rules -->` ブロックのためユーザー記述の消失はなく、
     生成文言自身が「コミットに含めよ」と指示している。S-1 のコミットに含めた
