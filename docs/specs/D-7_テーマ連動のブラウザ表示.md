# 仕様書: テーマ連動のブラウザ表示(D-7)

- ステータス: 承認済み(2026-10-02)
- 関連: [docs/specs/D-6_Structuredテーマ.md](D-6_Structuredテーマ.md) / [docs/specs/D-1-2_デザイン刷新.md](D-1-2_デザイン刷新.md) / [docs/specs/P3-3_PWA対応.md](P3-3_PWA対応.md) / `docs/指示資料/README.md` (今回の個別指示資料なし)
- Next.js の参照: `generate-viewport.md` / `14-metadata-and-og-images.md` / `app-icons.md` (Next.js 16.3.8 のローカルガイド)

## 目的

設定画面で選んだライト・ダーク・Structuredテーマを、ページ本体だけでなくブラウザの `theme-color` とタブのfaviconにも反映する。現在は `viewport.themeColor` と `app/icon.svg` が `prefers-color-scheme` に従うため、保存した手動テーマとOS設定が異なる場合に、ページとブラウザ表示が一致しない。

## 仕様

### 対象と前提

- テーマの保存先は既存どおり `localStorage` (`plandiff-theme`) とし、Cookieやサーバー側のテーマ保存は追加しない。
- Next.js の `viewport` / `generateViewport` は Server Component のexportであり、`localStorage` はサーバーから読めない。初回HTMLには現在の `prefers-color-scheme` に対応する静的なメタ情報を残し、描画前スクリプトは既存どおり `<html data-theme>` だけを設定する。ブラウザ向けメタ情報はhydration後とルート移動時にクライアントから同期し、Next.jsが管理する `<head>` をhydration前に変更しない。`generateViewport` をリクエストごとに動的化しない。
- Next.js の `app/icon.svg` 規約は `<link rel="icon">` を生成する。faviconのSVGはページ文書とは別に読み込まれるため、SVG内の `prefers-color-scheme` はOSの配色を参照するが、ページの `<html data-theme>` は参照できない。手動テーマのタブアイコン反映には、テーマ別の静的faviconを用意し、ページ側で既存のタブfaviconリンク先を切り替える。
- ブラウザタブのfaviconを対象とする。manifestの `icons`、`app/apple-icon.tsx`、インストール済みPWAのホーム画面/ランチャーアイコンは対象外とし、ページ内のテーマ変更でOSのアイコンが変わるとは約束しない。

### ブラウザ表示の対応

`<meta name="theme-color">` とブラウザのタブfaviconは、現在のページの有効テーマに同期する。既存テーマの色は維持し、Structuredの値は以下の承認値とする。

| 有効テーマ | `theme-color` | タブfavicon |
|---|---|---|
| ライト | 既存の `BRAND_COLOR` (`#2f4acb`) | 既存マークを群青で表示 |
| ダーク | 既存の `DARK_BACKGROUND_COLOR` (`#0e1116`) | 既存マークをダーク用の青 (`#4c6ef5`) で表示 |
| Structured | Structuredの背景 `--paper` (`#f9f7f3`) | 既存マークをStructuredのブランド色 (`#a05f58`) で表示 |

- 保存値が `light` / `dark` / `structured` の場合、描画前初期化と設定画面での選択変更の両方で、`data-theme`・`theme-color`・タブfaviconを同じテーマへ更新する。ページ再読み込みやルート遷移は発生させない。
- 保存値が `system`、未保存、不正値、または保存値を読み取れない場合は、`data-theme` の明示属性を付けずシステム追随とする。2つの `theme-color` media値と既存 `app/icon.svg` の `prefers-color-scheme` を維持し、OSのライト/ダーク切替にブラウザ自身が追随する。
- 同じタブの設定変更は既存の `THEME_CHANGE_EVENT` と連動する。明示テーマでは既存2つの `theme-color` のcontentを同じ選択色へ更新し、ライト/ダークそれぞれのmedia属性は保持する。OS設定に合う方のタグが選択色を返すため、OSテーマにかかわらずページと一致する。タグ数とNext.js管理下の要素識別属性を変えず、systemへ戻すと元の2つの色へ復元する。ブラウザメタ情報の更新でページ本体より先に別テーマを表示しない。
- 初期化時にlocalStorageを読めない場合はOS追随表示へフォールバックする。テーマ変更時にlocalStorage書き込みが失敗しても、そのページでは選択テーマとブラウザ表示を適用する。保存済みの値があればその値を保持し、次回読み込み時は保持された値を適用する。以前の値がなければ次回はシステム追随になる。どの場合も例外でページを壊さない。

### スコープ外

- manifest の `theme_color`、`icons`、`apple-touch-icon`、Service Worker、ホーム画面/ランチャーのインストール済みアイコン変更。
- アプリ本体のテーマトークン、テーマ選択肢、保存方式、Cookie、サーバー描画、ルーティングの変更。
- 全ブラウザでタブアイコンの更新タイミングが即時であることの保証。DOM上の指定が正しいことを自動検証し、対応ブラウザで表示も手動確認する。
- テーマ選択の別タブ間ライブ同期。テーマ本体の別タブ同期は既存仕様の範囲にとどめる。

## テストシナリオ

### 単体

- **S1** [単体]: Given `light` / `dark` / `structured` の有効テーマ When ブラウザ表示用の色とfaviconを解決 Then 上表の承認値を返す。
- **S2** [単体・境界値]: Given `system` / 未保存 / 不正値 / localStorage読み取り例外 When 初期化する Then 例外を画面へ漏らさず明示テーマを設定せず、OS追随用の表示へフォールバックする。

### コンポーネント結合

- **S3** [結合]: Given localStorageに `light` / `dark` / `structured` のいずれかが保存されている When 描画前テーマ初期化とhydration後のブラウザ表示同期が実行される Then `<html data-theme>`、2つの `theme-color` の色、タブfaviconの指定がすべて同じテーマになる。
- **S4** [結合]: Given設定画面が表示されている When ライト→ダーク→Structuredへ順に切り替える Then 各選択直後に色とタブfaviconが更新され、再読み込みなしで対応し、選択した値がlocalStorageへ保存される。
- **S5** [結合]: Given明示テーマを選択している When「システムに合わせる」へ戻す Then明示テーマの上書きを解除し、2つの `theme-color` media指定とOS連動faviconに戻る。
- **S6** [結合・異常系]: Given localStorageに `light` が保存されている When `structured` 選択時の書き込みが失敗する Then現在ページの `data-theme`・ブラウザ表示はStructuredへ更新され、既存の保存値 `light` は維持される。初期化を再実行するとライトへ戻り、例外を外へ漏らさない。保存値がなかった場合は次回読み込みでOS追随になる。

### ブラウザ確認

- **S7** [E2E]: Given保存済みテーマでページを開く When初期HTMLと描画後のheadを確認する Then `meta[name="theme-color"]` と `link[rel="icon"]` が保存済みテーマに対応し、手動切替後も再読み込みなしに更新される。Structuredから別ルートへ移動した後も指定が維持され、競合するメタタグが増えない。
- **S8** [手動・境界値]: Android Chrome / iOS Safariで保存済みテーマと切替を確認する。インストール済みPWAがある場合はブラウザのタブfaviconだけが対象で、ホーム画面/ランチャーアイコンは変わらないことを確認する。対象実機がない環境では未確認として記録する。

## 承認済みの判断(2026-10-02)

1. Structuredのブラウザ `theme-color` はページ背景色 `#f9f7f3` とする。
2. タブfaviconはテーマ別の静的SVGを用意して切り替え、Structuredアイコンはブランド色 `#a05f58` で表示する。
3. 実機確認はAndroid Chrome / iOS Safariを対象とする。対象実機がない場合は未確認として記録する。PWAランチャーアイコンをテーマ連動させる要望がある場合は、本仕様とは別にOSごとの配布・キャッシュ制約を含めて起票する。
