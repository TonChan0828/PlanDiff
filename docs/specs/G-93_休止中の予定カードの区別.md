# 仕様書: G-93 休止中の予定カードに時刻・繰り返し条件・休止開始日を表示する

- ステータス: 承認済み(2026-11-26)
- 関連: GitHub Issue #93 / [P10-2](P10-2_予定調整と休止提案.md)
- 指示資料: なし(2026-11-26 に確認。README のみ)

## 目的

「休止中の予定」のカードはタイトルしか出ないため、同じタイトルの予定が複数あると区別できない。

## 現況

`components/rule-pause-review.tsx` の2種類のカード(「記録が途絶えた予定」「休止中の予定」)は、どちらもタイトルと状態の文章だけを表示する。

## 仕様

- 両方のカードのタイトルの下に、次の1行を表示する: 「毎週月・水曜 22:00〜22:30」の形(繰り返し条件 + 開始〜終了時刻)
  - 繰り返し条件の表記は、提案カードと同じ `suggestionPatternLabel` を再利用する(毎日 / 毎週平日 / 毎週◯・◯曜)
  - 時刻はルールが持つローカル時刻(ルールのタイムゾーン)をそのまま表示する
  - 「記録が途絶えた予定」のカードも同じ区別の問題があるため対象にする(ルール id で `rules` から引く。見つからなければ行を出さない)
- 「休止中の予定」のカードには、さらに「休止開始: 2026/11/20」を表示する
  - 対象は、現在有効な(または開始予定の)休止期間の `startsOn`。再開予約済み(`endsOn` あり)の場合も、その休止期間の開始日を出す
  - 開始日が未来なら「休止開始予定: …」と表示する
- カードの `aria-label`(現在はタイトル)に繰り返し条件と時刻を加え、同名のカードを読み上げでも区別できるようにする
- 文言は `lib/calendar/messages.ts` に集約する
- DB・取得クエリは変えない(必要な情報は `recurringRules` にある)

## スコープ外

- 翌日の予定一覧と休止中ルールの関係の表示(Issue の「確認した実例」の2点目。時刻と繰り返し条件の表示で突き合わせられるようになる)

## テストシナリオ

日付はルールのタイムゾーンで扱い、基準時刻は props の `now` で固定する(R-1)。

- D1 [画面]: 同じタイトルで時刻・曜日が違う2件の休止中ルール → 2枚のカードに、それぞれの繰り返し条件と時刻が出る
- D2 [画面]: daily / weekdays / weekly(複数曜日)の表記が「毎日」「毎週平日」「毎週月・水曜」になる
- D3 [画面]: 休止中カードに「休止開始: 日付」が出る。再開予約済みでも出る
- D4 [画面・境界]: 休止の開始日が今日より後 → 「休止開始予定」。今日と同じ → 「休止開始」
- D5 [画面]: 過去に終わった休止と現在の休止がある場合、現在の休止の開始日を出す
- D6 [画面]: 「記録が途絶えた予定」のカードにも繰り返し条件と時刻が出る。対応するルールがなければ行を出さない(壊れない)
- D7 [画面]: 同名2件のカードが、`aria-label` で別々に取得できる
- D8 [UI]: 375px で横スクロール・崩れがない
