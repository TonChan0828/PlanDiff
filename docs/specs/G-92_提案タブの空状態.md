# 仕様書: G-92 「提案」タブが空のときに説明文を表示する

- ステータス: 承認済み(2026-11-26)
- 関連: GitHub Issue #92 / [P5-2](P5-2_実績からの予定提案.md) / [P5-7](P5-7_平日毎日まとめ提案.md)
- 指示資料: なし(2026-11-26 に `docs/指示資料/` を確認。README のみ)

## 目的

カレンダー右パネルの「提案」タブは、提案が0件だと何も表示されない。何を提案する機能で、どういう条件で提案が出るのかを画面で分かるようにする。

## 現況

`components/plan-suggestions.tsx` は、表示する提案が0件なら `null` を返す。ハイドレーション前も計算していないため0件になる。

## 仕様

- ハイドレーション後に表示する提案が0件のとき、空状態を表示する:
  - 見出し: 「いまは提案がありません」
  - 条件の説明: 「表示している週より前の4週間で、同じ名前の作業を同じ曜日の近い時刻(開始の差が1時間以内)に2週以上記録していると、これからの日時の予定として提案します。同じ日に同じ名前の予定がある作業や、その曜日の繰り返し予定を登録済みの作業(休止中・終了したものを含む)は表示しません。」
    (2026-11-26 改訂・ユーザー承認。初版の文言は実際の条件と食い違っていた: 対象は表示週より前の4週間で今週は数えない・過去の日時は提案しない・「回」ではなく週(日)で数える・除外は同じ日の同名の予定とその曜日の繰り返し予定)
- 実績の取得に失敗した場合は、空状態を出さずセクションを表示しない(P5-2 の仕様を維持する。`fetchSuggestionSourceEntries` は失敗時に `null` を返し、「該当なし」の空配列と区別する)
- 提案をすべて閉じた・追加した結果0件になった場合も、同じ空状態を表示する
- ハイドレーション前は、何も表示しない(まだ計算していないのに「提案がありません」と出さない)
- 説明の数値(4週間・1時間・2回)は `lib/calendar/suggestions.ts` の定数から組み立てる(定数を変えたときに文言がずれないように)。そのため定数を `export` する
- 文言は `lib/calendar/messages.ts` に集約する
- 提案の計算ロジックは変えない

## スコープ外

- 提案の条件の変更、却下の永続化

## テストシナリオ

- C1 [画面]: 提案が0件(実績なし) → 空状態の見出しと条件の説明が出る

- C3 [画面]: 唯一の提案を閉じる → 空状態に切り替わる

- C7 [画面・単体]: 取得に失敗した(`null`)ときはセクションを表示しない。`fetchSuggestionSourceEntries` は失敗で `null`、該当なしで空配列
