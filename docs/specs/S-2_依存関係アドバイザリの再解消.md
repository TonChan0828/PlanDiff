# 仕様書: S-2 依存関係アドバイザリの再解消

- ステータス: ドラフト(2026-10-01、`npm audit`の再失敗から起票)
- 関連: docs/開発計画.md Phase 14 / `.github/workflows/ci.yml`
- 発生元: P16改善の検証で、元lockfileと同じ high 5件・critical 1件を検出

## 目的

`npm audit --audit-level=high`を再び通し、CIが既知のhigh/critical advisoryを検出できる状態へ戻す。

## 仕様

- Next.jsはGHSA-vcvr-r3jv-pc5jの影響範囲(16.2.0以上16.3.6未満)に含まれるため、Next.jsと`eslint-config-next`を互換のある修正版へ揃える。
- `brace-expansion`、`browserslist`、`js-yaml`、`sharp`、`undici`等の監査対象推移依存を修正版へ更新する。
- `npm audit`を依存更新後にも再実行し、CI閾値以上の警告が残らないことを確認する。
- 現状の`next/og`利用は静的アイコン生成だけで、URLやユーザー入力をSVGへ渡していない。動的入力を追加しない。
- P16改善の依存差分は`@playwright/test`だけであり、監査対象とseverity件数は元lockfileと同じ。S-2の更新は別作業で行う。

## スコープ外

アプリ機能の変更、DB変更、通知設定、本番デプロイ。

## テストシナリオ

- S1 [単体]: 更新後の`npm audit --audit-level=high`が終了コード0で完了する。
- S2 [単体]: TypeScript、lint、全unit test、production buildが合格する。
- S3 [結合]: clean install後もlockfileに解決不能な依存差分がなく、CI監査ステップを同じコマンドで再現できる。
- S4 [レビュー]: `next/og`へ渡す画像値にリクエスト由来の文字列が含まれない。
