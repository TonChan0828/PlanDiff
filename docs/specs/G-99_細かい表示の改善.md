# 仕様書: G-99 細かい表示の改善(外観の表記・週表示の小さいブロック)

- ステータス: 承認済み(2026-11-26)
- 関連: GitHub Issue #99 / [D-6](D-6_Structuredテーマ.md) / [P11-1](P11-1_週表示の日付選択と編集導線.md)
- 指示資料: なし(2026-11-26 に確認。README のみ)

## 目的

実利用で気になった表示上の点を直す。Issue の3項目のうち、1と2をこの仕様で扱う。

## 現況

1. 設定の外観は「ライト／ダーク／システムに合わせる／Structured」。Structured だけ英語で、説明がない
2. 週表示の短いブロックはラベルが1〜2文字に省略される。ブロックをタップすると、実績は編集パネル、予定は計測の操作になる
3. 画面遷移のたびに `app/(app)/loading.tsx` の読み込み表示が出る。原因(サーバーの処理時間か、先読みの不足か)は未計測

## 仕様

### 1. 外観の表記

- 選択肢の名前を日本語の「あたたかい色」にする(承認時に確定)
- 選択肢の下に説明を1行出す: 「「あたたかい色」は、暖色系の明るい配色です(端末のダーク設定に関係なく明るい表示になります)。」
- 保存値(`structured`)は変えない(保存済みの設定はそのまま使える)。変更は表示の文言だけ

### 2. 週表示の小さいブロック

- 週表示の予定・実績ブロックに、`title` 属性でタイトル全文と時刻(`HH:mm〜HH:mm`)を付ける。マウスを重ねると全文が読める
  - 実績で差分・フリーの表示があるものは、`title` にも同じ内容を含める
- 読み上げ用の `aria-label` は現状を維持する(編集できない実績ブロックは、同じ内容が読めることを確認する)
- タップの動作は変えない。タッチ端末では、右パネル(日の一覧)と編集パネルで全文を確認できる
  - 長押しなどの新しい操作は足さない(タップの意味が変わると誤操作が増えるため)

### 3. 画面遷移の読み込み(この仕様では扱わない)

原因を測らずに先読みやキャッシュを足すと、効果が分からないまま挙動(データの新しさ)が変わる。
#99 から切り出して、計測の Issue [#130](https://github.com/TonChan0828/PlanDiff/issues/130) を作った(承認済み)。#99 はこの仕様の実装で閉じる。

## スコープ外

- テーマの配色の変更、ブロックの最小の高さや重なりのレイアウト変更

## テストシナリオ

- F1 [画面]: 外観の選択肢がすべて日本語で、説明の行が出る。`structured` の選択・保存・反映は従来どおり
- F2 [画面]: 週表示の予定ブロックの `title` に、タイトル全文と時刻が入る
- F3 [画面]: 紐づく実績ブロックの `title` に、タイトル・時刻・差分が入る。フリー実績は「フリー」が入る
- F4 [画面・境界]: タイトルが空のブロックは「(タイトルなし)」相当の既存の表記になる
- F5 [画面]: 既存の外観・週表示のテストが、文言の更新以外は変更なしで合格する
- F6 [UI]: 375px の設定画面で、外観の選択肢と説明が崩れない
